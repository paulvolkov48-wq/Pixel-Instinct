# Аксон — сайт для GitHub Pages

1. Распакуйте архив.
2. Создайте репозиторий на GitHub (например akson-site).
3. Загрузите содержимое архива в корень репозитория: index.html, .nojekyll и README.md. Не загружайте сам ZIP вместо файлов.
4. Откройте Settings → Pages.
5. В Source выберите Deploy from a branch, затем ветку main и папку / (root). Нажмите Save.
6. После завершения публикации ссылка появится в Settings → Pages.

Главная страница: index.html. Исходный HTML сохранён без изменения содержимого.
Стили, скрипты и изображения встроены в HTML.
Форма сохраняет бриф в текстовый файл на устройстве пользователя, а не отправляет заявку на сервер.

Документация: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
